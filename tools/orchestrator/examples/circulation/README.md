# MOX to MetricFlowX

The exported MOX CSV is the source node. **Filter MOX QAV** selects `time`
and signed `QAV`, converts mL/s to m³/s, and binds its output to the solver
inlet. The solver's parameter document is editable in the graph. The input
mesh, filtering script and terminal CSV are declared file nodes.

The ADAN56 smoke uses the normal-pressure source, the prepared ADAN56 mesh
and parameters from the integration example, zero refinements, and a 2 ms
solve. This exercises the file handoff and numerical startup. The upstream
8 s validation is tracked separately. [MOX inputs and model preparation](https://github.com/dealii-X/dealii-X/issues/42) · [ADAN56 validation](https://github.com/dealii-X/dealii-X/issues/33)

From the Platform checkout, with the orchestrator Python environment active:

```sh
example=tools/orchestrator/examples/circulation
workspace=$(mktemp -d)
mkdir "$workspace/inputs"
ln -s /path/to/electromechanics.csv "$workspace/inputs/electromechanics.csv"
ln -s /path/to/prepared/adan56/network/network.vtk "$workspace/inputs/adan56.vtk"
ln -s "$PWD/$example/filter_mox.py" "$workspace/inputs/filter_mox.py"
python "$example/prepare.py" --output "$workspace" --workspace "$workspace" \
  --python "$(command -v python)" --blood-flow /path/to/blood_flow \
  --parameters /path/to/prepared/adan56/parameters.prm
tools/orchestrator/orchestrator --configuration "$workspace/backend.config.json" \
  validate "$workspace/network.json"
tools/orchestrator/orchestrator --configuration "$workspace/backend.config.json" \
  run "$workspace/network.json"
```

For Slurm, put the same named inputs in the remote workspace and pass
`--host top`, the remote paths for `--workspace`, `--python` and `--blood-flow`,
and optionally `--partition`. `--output` and `--parameters` are local paths.
Use paths shared by the submission server and compute nodes. Add
`--full-adan56 --ranks 8 --mpi-launcher /remote/path/to/mpirun` to keep the
prepared case's full 8 s and run it with eight ranks.
If a runtime needs a library search path or thread limits, put them in the
target's `environment` section under `configuration` in `backend.config.json`. For the pinned
calibration build, use the compute-visible directory containing
`libmetric_flow_x.so` and set `DEAL_II_NUM_THREADS`, `OMP_NUM_THREADS` and
`OPENBLAS_NUM_THREADS` to `1`.
Open the generated `network.json` with the generated backend profile. CLI
run records, logs and output paths can also be inspected with the returned
run ID.

### Mock life-X heart source

Pass `--lifex-example-directory "$PWD/$example"` to `prepare.py` to generate
the MOX input file in the workflow. For a remote profile, copy `lifex_heart.py`
and `lifex_heart.parameters.json` to the directory on the target passed to this
option. The target needs `curl` and access to the
[dealii-X assets release](https://github.com/dealii-X/dealii-X/releases/tag/assets).

The mock downloads one published history and verifies its SHA-256 checksum.
Use **Configure** on the mock and choose `normal pressure` or `hypertension`.
The latter uses the severe systemic hypertension history. To drive this from
the canvas, expose `parameters / condition` as an input, add a **Selection**
node with `normal pressure | hypertension` in `options`, and connect its
**Selected value** output to the exposed input.

## ADAVN and IRCAD11 small on Slurm

Use the normal-pressure prepared ADAVN v3 PRM and the IRCAD11 small PRM from
the [16-rank native run](https://github.com/luca-heltai/immersx/issues/502).
Add `--ircad11 /path/to/ircad11_native_startup_cached`,
`--ircad11-parameters /local/path/to/ircad11.prm` and
`--mpi-launcher /remote/path/to/mpirun` to the generator command. Supply the
matching PETSc `blood_flow` build in `--blood-flow` and select the target's
Slurm partition with `--partition`. Put these inputs under `inputs/` in the
remote workspace:

| Name                                                                           | Source                                                    |
| ------------------------------------------------------------------------------ | --------------------------------------------------------- |
| `electromechanics.csv`                                                         | The unchanged normal MOX export, or generated by the mock |
| `filter_mox.py`, `filter_adavn.py`                                             | This directory                                            |
| `adavn_full.vtk`, `connections.csv`                                            | The prepared v3 ADAVN network                             |
| `ircad11.msh`                                                                  | The reduced IRCAD11 tissue mesh used in #502              |
| `ircad-network/manifest`, `ircad-network/part-0-0.txt` through `part-0-24.txt` | The constant-radius reduced vascular archive used in #502 |

`validate` checks the remote inputs, installed commands and all file bindings.
Produced files are checked as each stage runs. The arterial history sums
signed outflows at boundaries 900, 901 and 903–908. Boundary 1508 supplies
IVC pressure. The extractor requires the full 0–8 s terminal history and
preserves its native timestamps. This is a fresh-initialization workflow.
It does not import the checkpoint from the tracked simulation. The
orchestrator validates the network without launching the long solve.
